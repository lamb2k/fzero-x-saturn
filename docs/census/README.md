# Closure census (card G1.1)

Static census of the pinned decomp (`Zorkats/fzerox` `b944a41`, inside G-Diffuser `4f93206`)
for one human racer. Generated by `tools/census/closure.py`; classification rules with reasons
are in `overrides.tsv`. Regenerate, never edit the TSVs by hand.

## Method

- libclang parses every file under `src/game`, `src/sys` and `src/overlays` as the reference
  builds it: `PORT` and `EXPANSION_KIT` undefined, `NON_MATCHING` and `AVOID_UB` defined, US rev0,
  32-bit pointers, G-Diffuser's declaration-only asset headers. No ROM is needed.
- Tick roots, in `Race_Update`'s order (`src/overlays/ovl_i2/race.c:132`): `Menus_Update`,
  `Effects_Update`, `Racer_Update`, `Camera_Update`, `Background_Update`, `Course_Update`,
  `func_80074844`. Init root: `Race_Init`.
- Reachability does not pass through OUT functions; whatever is reached only through OUT code is
  OUT. Indirect calls: the only ones in the tick closure go through `D_800CF4B8`, the
  per-track-shape handler table (3 call sites), resolved by hand in the tool.
- Per function: lines, static float operations by kind, globals read and written by direct
  reference, `NON_MATCHING`, fork-hook source lines, active hook calls. Static counts only;
  per-tick dynamic counts come from the instrumented reference (G1.3). Writes through pointers
  (`racer->...` into `gRacers`) are not attributed to globals.

## Facts confirmed from source

- **Tick rate: 60 Hz.** One game frame per VI: `D_800CCFBC = 1` (`src/sys/sys_main.c:153`); race
  overlays leave it at 1. `gGameFrameCount` advances once per game frame (`sys_gfx.c:833`).
- **Tick order:** menus, effects, racers, camera, background, course, `func_80074844`. Input is
  latched before the race tick by `Controller_UpdateInputs` (platform, replaced by the Saturn pad).
- **Game mode:** `GAMEMODE_TIME_ATTACK` (`fzx_game.h`, value 0xE) is handled by `game.c` and
  `Racer_Update` (ghost recording at intro timer 255). It is the one-racer source path.

## Fork hooks

- 737 source lines in the reached closure mention `PORT`, `EXPANSION_KIT`, `gdx`/`Gdx`/`GDX_` or
  `CVar`; 130 of them are inside TICK functions. With `PORT` and `EXPANSION_KIT` undefined they are
  in inactive preprocessor branches.
- **Two hooks are live without `PORT`**, both outside the simulation: `Background_Init` calls
  `gdx_settings_view_wind_any` and writes `gGdxWindCloudTexture`; `func_80078104` (texture
  loading) calls `GDX_LoadRawRomAsset`. Both are OUT; the reference stubs them.
- No TICK function calls or references a fork symbol (column `active_hook_calls`).
- **Control (run in G1.2):** `racer.c` compiled with `PORT` defined, port hooks stubbed to
  return 0, changes the trace hash of every trace (the intro gate hook alone stops the race
  starting). The stock reference references none of them. A full `PORT` build is not possible
  outside G-Diffuser (it needs `EXPANSION_KIT` and the port runtime).

## NON_MATCHING

Four functions sit in `#ifdef NON_MATCHING` blocks: `Racer_Draw` (OUT), the Expansion Kit variant
of `func_8008D33C` (not built; the stock variant, which copies `sDefaultMachines` into
`gMachines`, matches), `func_8009DB28` (spline tensions, OFFLINE: "weird float/double
calculations") and `Matrix_SetAxisRotation` (OFFLINE). None is in the TICK closure.
`func_8009DB28` is where the reference's four-way check first diverged (G1.2): see
`ref/README.md`.

## Found while building the reference (G1.2)

- **Machine tuning reads the ROM.** `Racer_InitMachineStats` (OFFLINE) computes Blue Falcon's
  stats from 38 raw words of the ROM's first 4 KB (`ROM_READ(0x078)` ... `ROM_READ(0xA20)`), not
  from tables in the source. Retail tuning is therefore ROM-lane: the reference bakes it with
  `--rom`. The synthetic lane uses an authored constant word.
- **The sine table is computed at boot** by `Math_SinTableInit` (Taylor series in f64, rounded
  to f32; `sys_gfx.c:682`). It is not ROM data; G3.2 can bake it bit-exactly.
- **The starting grid is set in `cpu.c`** (`func_i3_80115E74`, called from
  `Racer_SetupStartPositions`). For one racer it reduces to `gRacers[0].position = gTotalRacers`;
  reclassified OFFLINE.
